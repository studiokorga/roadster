# Roadster

Roadster is a free configurator for 19" flight cases for theatre and live tech. Lay out a case, check whether everything fits (depth, power, phases, network, weight), view it in 3D and produce a parts list, packing list, print version and a request for the case builder.

**Open the app:** https://studiokorga.github.io/roadster/

- Works in any modern browser, no account needed.
- Your work is saved in your own browser. Use *Save file* / *Open file* to keep or share a project.
- Available in Dutch, English, German, French, Spanish and Italian.
- Works offline: download `index.html` and open it in a browser.

Device data comes from manufacturer datasheets; values marked ≈ are estimates. Always check critical dimensions before building a case.
